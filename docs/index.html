Installer på 30 sekunder

n8n community nodes installeres direkte fra n8n-GUI-en. Du trenger ikke tilgang til serveren eller å redigere konfigurasjonsfiler.

1

Åpne Community Nodes

I n8n: Settings → Community Nodes. Klikk Install.

2

Skriv inn pakkenavnet

Lim inn: n8n-nodes-firmaradar. Godkjenn risiko-bekreftelsen og klikk Install.

3

Legg til API-nøkkel

I node-konfigurasjonen: Credentials → New → Firmaradar API. Lim inn nøkkelen din fra firmaradar.no.

21 operasjoner i fem grupper

Hver operasjon returnerer et strukturert JSON-objekt med kildehenvisning og ferskhets-stempel. Full skjema-dokumentasjon på firmaradar.no/dokumentasjon.

🏢 Selskap

  • Search companies — søk på navn eller orgnr
  • Get company — full profil
  • Get ownership — konsernhierarki opp og ned
  • Get roles — styre, daglig leder, prokura
  • Get financials — årsregnskap og nøkkeltall
  • Get announcements — BRREG-kunngjøringer
  • Get signals — risiko- og KYC-flagg
  • Find related — via eier, rolle eller adresse

👤 Person

  • Search persons — navne-søk med skrivefeil-toleranse
  • Get person — profil og fødselsår
  • Get companies — eier- og rolle-koblinger
  • Get roles — aktive og historiske roller

⚖️ KYC og AML

  • Check AML/PEP — sanksjonslister og PEP
  • Get AML score — strukturert risikoscore 0–100
  • Get risk score — generell risiko-vurdering
  • Check foretak i vanskeligheter — FIV-status (a–e)

📈 Bransje og overvåkning

  • List companies in NACE — bransje + geografi
  • Get recent changes — siste N dager
  • Search announcements — fritekst-søk
  • Compare companies — side om side

🏛️ Offentlige data

  • Get konsernstøtte — NAV-tildelinger og koronastøtte
  • Get skattelister — inntekt, formue, skatt

Tre ferdige arbeidsflyter du kan importere

Lim inn JSON-en i n8n via Workflows → Import from File og tilpass til ditt oppsett.

🪪 KYC-onboarding

CRM-trigger → AML/PEP + eierstruktur + risikoscore → Slack-varsel ved høy risiko

Når en ny kunde registrerer seg, kjører automatisk full screening og varsler compliance-teamet hvis risikoscoren overstiger terskelen din.

🚨 Konkurs-overvåkning

Daglig cron → sjekk portefølje for konkurssignaler → e-post + Teams-varsel

Daglig gjennomgang av selskaper i kundeporteføljen din. Varsler ved foretak-i-vanskeligheter-status eller nye BRREG-kunngjøringer.

📋 Konsern-due-diligence

Manuell trigger → konsernhierarki → finansiell rollup → AML på alle nivåer → PDF

Gitt et enkelt orgnr, bygg en fullstendig due-diligence-rapport som dekker hele konsernet og eksporterer som PDF for compliance-arkivet.

Auth API-nøkkel via n8n-legitimasjon OAuth 2.0 eller API-nøkkel
Datakilde Samme Firmaradar API Samme Firmaradar API
